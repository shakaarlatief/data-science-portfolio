# Data Science, Machine Learning and Data Engineering Portfolio

This repository provides an overview of my applied work across data science, machine learning, econometrics, artificial intelligence, and data engineering.

The projects combine statistical and machine-learning foundations with practical implementation, software engineering, experimentation, reproducibility, and increasingly the systems required to move data and models toward production use.

The repositories below are selected public projects. Additional private and in-development work is not listed here.

## Featured public projects

### Autonomous Data Science System

Repository: https://github.com/shakaarlatief/autonomous-data-science-system

A research and engineering project exploring how to build a rigorous, adaptive, semi-autonomous system for carrying out data-science projects from problem understanding through analysis, experimentation, modelling, evaluation, reporting, and delivery.

The current Prototype V0 includes executable Python infrastructure, automated tests, provider-neutral model interfaces, structured project state, reusable knowledge activation, benchmark generation, deterministic evaluation, experiment supervision, and a preregistered held-out comparison against simpler strong-LLM workflows.

### Interactive Regression Likelihood Explorer

Repository: https://github.com/shakaarlatief/interactive-regression-likelihood

Live application: https://shakaarlatief.github.io/interactive-regression-likelihood/

An interactive browser-based visualization of maximum likelihood estimation and ordinary least squares in a normal homoskedastic linear regression. The application connects probability distributions, residual geometry, SSE, likelihood optimization, and the OLS/MLE relationship through an interactive interface.

Technical elements include vanilla JavaScript, Plotly.js, responsive frontend design, deterministic sample generation, and automated GitHub Pages deployment.
